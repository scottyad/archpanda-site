1. Executive Summary & Privacy Principles

Obsidian Citation Capture is an open-source, academic research productivity tool designed to capture bibliographic citations, extract scholarly metadata, and write structured literature notes directly into your local Obsidian vault.

Our architectural philosophy is founded on the principle of User Sovereignty and Data Minimization:

Core Privacy Commitments:
  • Zero Tracking: We never track browsing history, pages visited, or research queries.
  • Zero Telemetry: No analytics libraries, crash loggers, or behavioral profiling tools are loaded.
  • Zero Monetization: We do not sell, rent, monetize, or trade your personal or research data.
  • Local-First: Parsing, formatting, and note generation run locally on your device.

2. Zero Tracking & Telemetry Policy

Obsidian Citation Capture operates with strict data isolation:

  • No Third-Party Trackers: No Google Analytics, Mixpanel, Segment, PostHog, or tracking pixels are bundled or loaded.
  • No Background Surveillance: The content script activates solely to scrape academic metadata when you explicitly request capture (by clicking the extension toolbar icon, opening the popup, or choosing a right-click context menu item).
  • No Keystroke or Form Logging: The extension never inspects input forms, passwords, payment info, or unrelated page interactions.
  • No Device Fingerprinting: The extension does not inspect canvas hashes, WebGL profiles, audio contexts, or system font rosters to fingerprint your hardware.

3. Data Collection and Local Storage Disclosures

3.1 What Data Is Stored

To operate as configured by you, the extension saves configuration preferences within Chrome's native storage APIs (chrome.storage.sync and chrome.storage.local):

  • Target Vault Name: Name of your target Obsidian vault (e.g., ResearchVault).
  • Literature Folder Path: Directory path where generated notes are stored (default: Literature).
  • Custom Markdown Template: Note template structure, YAML frontmatter formatting, and variable substitutions.
  • Bridge Mode Selection: Note dispatch method (obsidian-uri, local-rest, plugin-protocol, or clipboard).
  • Local REST API Configuration: Loopback port (default: 27124) and bearer token used strictly to communicate with Obsidian Local REST API on loopback.
  • AI Configuration Preferences: Selected mode (auto, ollama, cloud, byok, or none), Ollama endpoint (http://localhost:11434), model name, and cloud proxy URL.
  • BYOK Credentials: Optional user-supplied API keys for Anthropic Claude or OpenAI.
  • Licensing & Capture Count: License key, tier status (Free, Pro, Pro+, Lifetime), and local capture count.

3.2 Where and How It Is Stored

Chrome Profile Synchronization: General configuration parameters (vault name, folder path, template, bridge preference) are synced across your signed-in Google Chrome profile via Google's encrypted Chrome Sync infrastructure (chrome.storage.sync). We do not host or operate intermediary configuration servers.

Device-Local Secrets: Sensitive credentials (BYOK API keys and Obsidian Local REST API bearer tokens) are stored locally in physical storage (chrome.storage.local) on your current device. They are never transmitted to our servers.

4. External Academic APIs & Bibliographic Enrichment

When you capture a paper with a registered identifier (DOI, arXiv ID, or PubMed ID), the extension may query public scholarly repositories to retrieve official BibTeX records and verified metadata.

Academic Service Endpoint Queried Data Sent Purpose
International DOI Foundation https://doi.org/* DOI identifier only Content negotiation for canonical publisher BibTeX
CrossRef REST API https://api.crossref.org/* DOI identifier only Resolving author rosters, publication years, and journal titles
arXiv Export API https://export.arxiv.org/* arXiv ID only Parsing preprint metadata, author list, abstract, and category
NCBI PubMed E-Utilities https://eutils.ncbi.nlm.nih.gov/* PubMed PMID only Retrieving MEDLINE publication records for medical articles

Privacy Guarantee: These requests contain only the public paper identifier. No cookies, account names, user IP proxies, or browsing histories are attached. You can turn off automatic enrichment at any time in Options.

5. Obsidian Vault Bridge & Local Loopback Networking

The extension provides three mechanisms to transfer literature notes into your local Obsidian vault:

  • Obsidian URI Scheme (obsidian://new): Dispatches formatted markdown notes via the OS-registered Obsidian desktop protocol handler. Runs 100% offline via local IPC. Zero network transmission.
  • Obsidian Local REST API (https://127.0.0.1:27124): Dispatches notes in the background via HTTP PUT to the Obsidian Local REST API community plugin. Traffic stays strictly within your RFC 1122 loopback interface (127.0.0.1) and never leaves your computer.
  • System Clipboard (clipboardWrite): Directly copies formatted BibTeX, APA, MLA, or Markdown citations to your system clipboard for manual pasting.

7. Data Retention, Export, and Deletion Rights

Zero Remote Retention: We operate no remote user databases. Captured notes reside exclusively inside your own Obsidian vault on your hard drive.

Complete Data Deletion:

  • Uninstalling the extension from Chrome removes all locally stored preferences, keys, and custom templates.
  • You can reset stored options at any time via the "Reset to Defaults" button on the extension Options page.
  • Your existing notes in Obsidian remain intact on your computer because they are regular Markdown files under your complete ownership.

8. Security Safeguards

  • Manifest V3 Compliance: Uses Google's modern extension platform architecture with service workers and declarative rules.
  • Strict CSP: No eval(), no remote script loading, and no dynamic code execution. All extension code is pre-compiled and bundled locally.
  • Loopback Isolation: Outbound local requests are restricted strictly to loopback addresses (localhost, 127.0.0.1) on designated ports.

9. Regulatory Compliance Disclosures

CCPA / CPRA: We do not sell or share personal consumer information. No behavioral profiling or cross-site tracking is conducted.

GDPR: No personal user data is processed by external servers. Outbound queries to public academic repositories are initiated under legitimate interest to fulfill the user's explicit request for citation data.

COPPA: We do not knowingly collect or solicit information from children under 13.
